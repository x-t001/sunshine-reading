# Sunshine Reading Web

前端应用目录（`apps/web`），基于 Next.js + TypeScript + App Router + Tailwind CSS。

当前版本说明：
- 使用 mock 数据构建基础阅读平台页面。
- 不接真实后端接口，不接数据库。
- 不包含登录、支付、会员等复杂功能。

已提供路由：
- `/`
- `/novels`
- `/novels/[id]`
- `/novels/[id]/chapters/[chapterId]`
- `/categories`
- `/rankings`
- `/search`
- `/bookshelf`
