# 阳光阅读项目路线图

## 文档目的
本文档用于定义“阳光阅读 Sunshine Reading”从 0 到 1 再到规模化的分阶段建设路线，作为产品、设计、前后端、测试协同的统一里程碑依据。

## 当前阶段约束
- 当前仓库阶段仅允许编写规范文档。
- 禁止初始化 Next.js、Django 项目。
- 禁止编写业务功能代码。

## 阶段总览
- 第一阶段：基础阅读平台
- 第二阶段：用户书架和阅读历史
- 第三阶段：搜索、分类、排行榜
- 第四阶段：作者端
- 第五阶段：管理端
- 第六阶段：App 打包
- 第七阶段：推荐、会员、付费扩展

## 第一阶段：基础阅读平台
### 目标
- 用户可完成“浏览小说 -> 打开详情 -> 进入章节阅读 -> 切换章节”的主流程。

### 范围
- 小说列表页、小说详情页、阅读页。
- 章节内容加载与翻页。
- 基础分类浏览（仅展示，不做复杂筛选）。

### 交付清单
- 前端页面信息架构与 UI 规范文档。
- 后端 API 草案（小说、章节读取相关）。
- 核心数据模型文档（Novel、Chapter、Category）。
- 基础接口联调测试用例清单。

### 验收标准
- 阅读主路径可用率达到 99%（联调测试场景）。
- 关键页面首屏加载策略明确且有兜底。
- API 返回结构和错误码符合统一规范。

## 第二阶段：用户书架和阅读历史
### 目标
- 用户可收藏小说、查看书架、自动记录阅读进度并续读。

### 范围
- 书架管理（加入、移除、置顶可选）。
- 阅读历史记录与最近阅读入口。
- 登录态绑定阅读进度。

### 交付清单
- Bookshelf、ReadingHistory 数据模型设计。
- 书架与阅读历史接口规范。
- 前端书架页、最近阅读模块交互规范。

### 验收标准
- 阅读续读命中率可验证。
- 书架操作具备幂等处理策略。
- 用户切换设备后进度同步策略明确。

## 第三阶段：搜索、分类、排行榜
### 目标
- 建立内容发现能力，提升找书效率与留存。

### 范围
- 关键词搜索（书名、作者、标签）。
- 分类页和筛选排序。
- 榜单页（热度榜、新书榜、评分榜）。

### 交付清单
- 搜索索引字段方案与同步策略文档。
- 分类与榜单 API 规范。
- 搜索无结果与纠错建议交互规范。

### 验收标准
- 搜索响应延迟目标和监控指标明确。
- 榜单更新频率、计算口径可追溯。
- 分类筛选规则可复现。

## 第四阶段：作者端
### 目标
- 作者可提交作品、管理章节并发布。

### 范围
- 作品创建与编辑。
- 章节草稿、发布、撤回。
- 作者内容状态流转（草稿/已发布/下线）。

### 交付清单
- 作者端权限矩阵。
- Novel、Chapter 扩展字段定义。
- 作者端接口与审核流程文档。

### 验收标准
- 状态流转可控且可审计。
- 权限边界覆盖“作者仅管理自身作品”。
- 发布失败具备回滚策略。

## 第五阶段：管理端
### 目标
- 平台可进行内容管理、用户管理、运营配置。

### 范围
- 内容审核、上下架。
- 用户管理与违规处理。
- 栏目、榜单、推荐位基础配置。

### 交付清单
- 管理端角色权限模型（运营、审核、超级管理员）。
- 审计日志规范与操作留痕方案。
- 管理端关键页面信息架构文档。

### 验收标准
- 高风险操作全量审计。
- 管理操作具备二次确认机制。
- 权限越权测试用例通过。

## 第六阶段：App 打包
### 目标
- 将阅读能力发布到移动端 App，统一体验。

### 范围
- 通过 Capacitor 封装 Web 应用。
- 处理移动端生命周期与缓存策略。
- 适配推送、分享、启动参数（按优先级逐步接入）。

### 交付清单
- App 容器适配清单。
- Web 与 App 差异行为规范。
- 发布流程和版本管理文档。

### 验收标准
- 核心阅读流程在 App 内稳定可用。
- 启动、页面切换、断网恢复行为明确。
- 版本回滚和热修复策略明确。

## 第七阶段：推荐、会员、付费扩展
### 目标
- 建立商业化与个性化能力，提升留存和付费转化。

### 范围
- 个性化推荐（召回与排序策略分层）。
- 会员体系（权益、有效期、状态）。
- 付费章节、订单、支付回调与对账。

### 交付清单
- 推荐链路和特征字段规范。
- 会员与付费域模型设计。
- 风控与支付安全规范。

### 验收标准
- 推荐效果指标体系定义清晰。
- 会员权益校验链路可追踪。
- 付费链路具备幂等、防重与审计能力。

## 里程碑执行规则
- 每阶段开始前先冻结范围，输出“范围内/范围外”清单。
- 每阶段结束前必须完成：接口契约评审、权限评审、数据模型评审。
- 所有阶段均遵循统一 API 规范与数据库设计规范。
