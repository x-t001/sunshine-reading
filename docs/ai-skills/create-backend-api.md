# 技能：创建后端 API

## 目的
- 构建严格遵循统一响应与权限规则的后端 API。

## 输入
- 接口目的
- 请求与响应结构
- 权限要求

## 步骤
1. 定义接口契约，包括路径、请求方法、版本和角色权限。
2. 实现请求校验规则，包括类型、范围、必填项和格式。
3. 实现服务逻辑，并将输出映射到统一响应封装。
4. 定义确定的错误码和字段级校验错误。
5. 使用成功、校验失败、权限拒绝和资源不存在四类用例进行验证。

## 产出
- 与项目契约一致的 API 交付清单。

## 检查清单
- [ ] 接口契约明确。
- [ ] 响应格式统一。
- [ ] 已包含权限检查。
- [ ] 已列出核心测试。
