# 技能：创建阅读功能

## 目的
- 构建端到端阅读功能，保持体验稳定并遵循后端接口契约。

## 输入
- 阅读场景
- 功能验收标准
- API 与数据依赖

## 步骤
1. 定义阅读流程：进入章节 -> 渲染内容 -> 用户交互 -> 保存进度。
2. 定义章节加载、章节不存在、付费或权限受限以及重试状态。
3. 定义章节内容与阅读进度的 API 调用和缓存策略。
4. 定义字体设置、主题切换、章节导航和滚动恢复等体验约束。
5. 使用首次阅读、断点续读和跨端同步失败兜底等场景进行验证。

## 产出
- 覆盖关键场景的阅读功能实现清单。

## 检查清单
- [ ] 阅读流程完整。
- [ ] 状态处理完整。
- [ ] API 与缓存策略清晰。
- [ ] 已验证核心阅读场景。
