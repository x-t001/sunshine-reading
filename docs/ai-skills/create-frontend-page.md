# 技能：创建前端页面

## 目的
- 以可预测、可测试的流程创建阅读平台页面。

## 输入
- 路由与用户角色
- 页面目标与验收标准
- 所需 API

## 步骤
1. 定义页面契约，包括路由、角色守卫和所需 API 响应。
2. 按 `page`、`feature`、`shared component` 分层拆分 UI，并明确各层职责。
3. 定义加载、空态、成功、错误和无权限状态。
4. 将 API 字段映射到类型化视图模型，并处理兜底值。
5. 完成前验证可访问性与响应式行为。

## 产出
- 可执行的页面实现检查清单。

## 检查清单
- [ ] 路由与守卫已定义。
- [ ] 分层清晰。
- [ ] 所有状态均已处理。
- [ ] 已验证可访问性与响应式行为。
