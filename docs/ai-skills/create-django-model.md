# 技能：创建 Django 模型

## 目的
- 创建迁移安全且查询友好的 Django 模型。

## 输入
- 实体定义
- 关系图
- 查询与排序模式

## 步骤
1. 明确定义模型字段的类型、可空性、默认值和业务语义。
2. 根据查询路径增加唯一约束和索引。
3. 明确定义关联关系与 `on_delete` 行为。
4. 包含标准审计字段，并按需增加软删除字段。
5. 评审迁移风险，包括数据回填、锁影响和回滚策略。

## 产出
- 可直接实施并迁移的模型定义清单。

## 检查清单
- [ ] 字段语义明确。
- [ ] 索引与唯一约束有明确依据。
- [ ] 关联行为明确。
- [ ] 已评审迁移风险。
