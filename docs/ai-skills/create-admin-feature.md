# Skill: Create Admin Feature / 创建管理功能

## Purpose / 目的
- Implement admin-side features with strong audit and permission controls.
- 实现具备严格审计与权限控制的管理端功能。

## Inputs / 输入
- Admin operation scope / 管理操作范围
- Role matrix / 角色矩阵
- Compliance/audit requirements / 合规与审计要求

## Steps / 步骤
1. Define admin role and action permissions. / 定义管理角色与动作权限。
2. Define operation guards and approval requirements. / 定义操作防护与审批要求。
3. Define audit log fields for admin actions. / 定义管理动作审计日志字段。
4. Define failure handling and rollback strategy. / 定义失败处理与回滚策略。
5. Define tests for permission escalation prevention. / 定义防权限提升测试。

## Output / 产出
- Admin feature implementation checklist.
- 管理功能实施检查清单。

## Checklist / 检查清单
- [ ] Role matrix mapped / 角色矩阵已映射
- [ ] Guardrails defined / 防护规则已定义
- [ ] Audit logs specified / 审计日志已明确
- [ ] Security tests listed / 安全测试已列出
