# Skill: Create Author Feature / 创建作者功能

## Purpose / 目的
- Implement author-side capability with ownership and content integrity.
- 实现具备所有权约束与内容完整性的作者端能力。

## Inputs / 输入
- Author workflow / 作者工作流
- Data ownership rules / 数据归属规则
- Validation requirements / 校验要求

## Steps / 步骤
1. Define author actions and permission boundaries. / 定义作者动作与权限边界。
2. Define create/edit/publish state transitions. / 定义创建/编辑/发布状态流转。
3. Define validation and conflict handling rules. / 定义校验与冲突处理规则。
4. Define API and UI feedback for each transition. / 定义各状态转换的 API 与 UI 反馈。
5. Define tests for ownership and invalid operations. / 定义归属与非法操作测试。

## Output / 产出
- Author feature implementation checklist.
- 作者功能实施检查清单。

## Checklist / 检查清单
- [ ] Ownership enforced / 所有权已强约束
- [ ] State transitions explicit / 状态流转明确
- [ ] Validation complete / 校验完整
- [ ] Negative tests included / 包含负向测试
