# 技能：排查后端缺陷

## 目的
- 定位请求校验、权限、服务逻辑和数据层中的后端故障。

## 输入
- 错误日志与 `request_id`
- 失败接口
- 可疑的近期改动

## 步骤
1. 使用原始请求数据与操作角色复现故障。
2. 按 `view -> serializer -> service -> model/query` 追踪调用链路。
3. 在检查业务逻辑前，先核对权限矩阵与输入校验。
4. 如果问题涉及性能或完整性，检查数据库约束与索引影响。
5. 实施最小修复，并使用成功、失败、无权限和资源不存在用例进行验证。

## 产出
- 后端缺陷诊断与修复验证清单。

## 检查清单
- [ ] 已定位故障边界。
- [ ] 已检查权限与校验。
- [ ] 已评估数据层影响。
- [ ] 已执行回归测试。
